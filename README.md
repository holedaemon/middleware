# middleware

A collection of useful middlewares for any stdlib-compliant HTTP mux, namely [chi](https://github.com/go-chi/chi).

# Credits

The Recoverer, RequestID, RequestLogger and Logger middlewares were originally written by [Zikaeroh](https://github.com/zikaeroh) for [HortBot](https://github.com/hortbot/hortbot).
